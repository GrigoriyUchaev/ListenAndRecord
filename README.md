# ListenAndRecord

Приложение для Mac (Apple Silicon, macOS 14+) для записи видеозвонков и локальной расшифровки речи.

## Возможности

**Запись созвона**
- Записывает **голоса всех участников**: звук созвона (системный звук — работает с Zoom, Google Meet, Teams, Telegram, FaceTime, WhatsApp и любым другим приложением) + ваш микрофон. Дорожки синхронизируются и сводятся в один файл.
- Кнопки **Начать запись / Пауза / Продолжить / Стоп** — в окне, в меню и в строке меню (значок вверху экрана), горячие клавиши: ⌘R, ⇧⌘P, ⌘.
- После остановки — ввод имени файла, выбор формата и папки для сохранения.
- Форматы: **M4A (AAC)**, **MP3**, **WAV**.
- Индикаторы уровня громкости для микрофона и звука созвона.
- Если приложение закрылось во время записи, несохранённая запись будет предложена при следующем запуске.

**Расшифровка**
- Выбор любого аудио/видео файла (или перетаскивание в окно): M4A, MP3, WAV, AIFF, FLAC, MP4, MOV…
- Результат в **TXT** или **DOCX** (Word), по желанию — с временными метками абзацев.
- Распознавание **полностью локально** через whisper.cpp (Metal, ускорение на GPU M3), без интернета и подписок.

## Почему whisper и как решена проблема «потери» речи после пауз

Для русского языка лучший бесплатный локальный распознаватель на сегодня — Whisper large-v3 / large-v3-turbo. Поэтому приложение использует ваш whisper.cpp и вашу модель `ggml-large-v3-turbo`, но запускает их иначе, чем по умолчанию.

Пропуски после пауз возникают из-за того, что Whisper при распознавании опирается на ранее распознанный текст и на «тишину» в окне 30 секунд: после длинной паузы он сбивается, зацикливается или «перепрыгивает» оставшуюся часть. В приложении:

1. **Нарезка по паузам.** Аудио делится на фрагменты до ~60 с по местам тишины; длинная тишина вырезается.
2. **Без «памяти» между фрагментами** (`--max-context 0`): ошибка в одном месте не тянется дальше.
3. **Silero VAD** внутри whisper.cpp — точный детектор речи, убирающий тишину и шумы (модель ~1 МБ, скачивается один раз кнопкой в настройках).
4. **Проверка и восстановление.** После распознавания приложение ищет участки, где речь есть, а текста нет (или слишком мало), и распознаёт их повторно короткими кусками без VAD. Результат берётся, только если он действительно полнее.
5. **Чистка галлюцинаций**: «Продолжение следует…», «Субтитры сделал…», «Спасибо за просмотр», зацикленные повторы.
6. Beam search (5) для большей точности.

## Установка

1. Нужны Command Line Tools (если ещё не стоят):
   ```bash
   xcode-select --install
   ```
2. whisper.cpp (у вас уже установлен; если нет или он старый — обновите, чтобы работал VAD):
   ```bash
   brew install whisper-cpp     # или: brew upgrade whisper-cpp
   ```
3. Для сохранения в MP3 (M4A и WAV работают без этого):
   ```bash
   brew install lame
   ```
4. Сборка приложения:
   ```bash
   git clone <этот репозиторий> ListenAndRecord
   cd ListenAndRecord
   ./scripts/build_app.sh
   cp -R build/ListenAndRecord.app /Applications/
   ```
   Готовую сборку также можно скачать во вкладке **Actions** репозитория (артефакт `ListenAndRecord`).

5. Первый запуск: так как приложение подписано локально (ad-hoc), откройте его правой кнопкой → **Открыть**.

## Разрешения macOS

При первой записи macOS попросит:
- **Микрофон** — для вашего голоса;
- **Запись экрана и системного звука** — нужно для захвата звука созвона (видео не записывается). Включите ListenAndRecord в *Системные настройки → Конфиденциальность и безопасность → Запись экрана и системного звука* и перезапустите приложение.

Совет: при пересборке ad-hoc-подписанного приложения macOS может заново спросить разрешения — это нормально.

## Настройки расшифровки

Во вкладке **Настройки** приложение само ищет `whisper-cli` и модель (`ggml-large-v3-turbo.bin`) — через Spotlight и в типичных папках. Если не нашло — укажите пути вручную кнопками «Выбрать…». Там же — скачивание модели Silero VAD и переключатели защиты от пропусков.

Для максимальной точности можно указать модель `ggml-large-v3.bin` (в 3–4 раза медленнее turbo).

## Советы для качественной записи

- Говорите в **наушниках**: тогда голоса собеседников не попадают в микрофон повторно (без эха).
- Не выключайте звук созвона на Mac — приложение пишет то, что воспроизводится.

## Структура кода

```
Sources/ListenAndRecord/
  App/            — точка входа, настройки, контроллер расшифровки
  Recording/      — захват звука (ScreenCaptureKit + AVAudioEngine), синхронизация, экспорт
  Transcription/  — декодирование, нарезка по паузам, запуск whisper, чистка, TXT/DOCX
  Support/        — WAV, ZIP (для DOCX), поиск внешних утилит
  Views/          — интерфейс SwiftUI
```
