# ListenAndRecord

<img src="Resources/AppIcon.png" width="96" align="right" alt="icon">

Запись видеозвонков и локальная расшифровка речи для **macOS** (Apple Silicon, macOS 14+) и **Windows 10/11** (x64).

## Возможности

**Запись созвона**
- Записывает **голоса всех участников**: звук созвона (Zoom, Google Meet, Teams, Telegram, FaceTime, Discord, WhatsApp — любое приложение) + ваш микрофон. Дорожки синхронизируются и сводятся в один файл.
- Кнопки **Начать / Пауза / Продолжить / Стоп**.
  - Mac: в окне, в строке меню (значок вверху экрана), горячие клавиши ⌘R, ⇧⌘P, ⌘.
  - Windows: в окне и глобальные горячие клавиши из любого приложения: Ctrl+Alt+R, Ctrl+Alt+P, Ctrl+Alt+S.
- После остановки — имя файла, формат и папка для сохранения. Форматы: **M4A (AAC)**, **MP3**, **WAV**.
- Несохранённая запись не теряется, если приложение закрылось — она будет предложена при следующем запуске.

**Расшифровка**
- Любой аудио/видео файл (или перетаскивание в окно) → **TXT** или **DOCX**, по желанию с временными метками.
- **Распознаватель встроен в приложение** (whisper.cpp), работает полностью локально, без интернета и подписок. Интернет нужен только один раз — скачать модель прямо из приложения (вкладка «Модели и настройки»).
- Выбор модели внутри приложения с рекомендацией под ваш компьютер.

## Как решена проблема «потери» речи после пауз

1. **Нарезка по паузам**: аудио делится на фрагменты до ~60 с по местам тишины, длинная тишина вырезается.
2. **Без «памяти» между окнами** (`no_context`, `max-context 0`): Whisper не опирается на ранее распознанный текст — именно из-за этого он зацикливается и пропускает речь.
3. **Silero VAD** — точный детектор речи (модель ~1 МБ, скачивается кнопкой).
4. **Проверка и восстановление**: участки, где речь есть, а текста нет (или мало), распознаются повторно короткими кусками.
5. **Чистка галлюцинаций**: «Продолжение следует…», «Субтитры сделал…», повторы.

Это проверяется автоматически при каждой сборке: тестовая запись с паузами 25 и 40 секунд должна быть расшифрована целиком.

## Модели

| Модель | Размер | Для чего |
|---|---|---|
| Large v3 Turbo | 1,6 ГБ | **Mac M1–M4** — рекомендуется |
| Large v3 Turbo (сжатая) | 0,6 ГБ | **Современные ПК** (Ryzen 5 5600H и т.п.) — рекомендуется |
| Large v3 / сжатая | 3 / 1 ГБ | Максимальная точность, медленнее в 3–4 раза |
| Medium (сжатая) | 0,5 ГБ | Средняя скорость |
| Small | 0,5 ГБ | **Старые/слабые ПК** (4 ГБ памяти, процессор без AVX2, например Core i5-760) |
| Base | 0,15 ГБ | Только для пробы |

Можно добавить и свой файл модели `ggml-*.bin`. На Mac приложение само находит модели, которые уже есть на диске.

## Установка — macOS

Готовая сборка: вкладка **Actions** репозитория → последний успешный запуск → артефакт `ListenAndRecord-macOS`.
Распакуйте скачанный ZIP один раз, откройте **ListenAndRecord.dmg** и перетащите **ListenAndRecord.app**
на ярлык **Applications («Программы»)** в открывшемся окне. При обновлении сначала завершите старую программу через ⌘Q,
а при копировании выберите «Заменить». После установки извлеките образ через Finder.

Или сборка самостоятельно (нужны только Command Line Tools):
```bash
xcode-select --install        # если ещё не стоят
git clone https://github.com/GrigoriyUchaev/ListenAndRecord && cd ListenAndRecord
./scripts/build_app.sh
rm -rf /Applications/ListenAndRecord.app && cp -R build/ListenAndRecord.app /Applications/
```
Первый запуск — правой кнопкой → **Открыть**. При первой записи разрешите **Микрофон** и **Запись экрана и системного звука** (нужно для звука созвона, видео не пишется), затем перезапустите приложение.

Для MP3 на Mac нужен кодировщик: `brew install lame` (M4A и WAV работают без него).

## Установка — Windows 10/11

Вкладка **Actions** репозитория → последний успешный запуск → артефакт `ListenAndRecord-Windows`:
- `ListenAndRecord-Setup.exe` — установщик (права администратора не нужны);
- `ListenAndRecord-Windows-portable.zip` — версия без установки (распаковать и запустить `ListenAndRecord.exe`).

Windows может показать предупреждение SmartScreen (приложение без цифровой подписи): «Подробнее» → «Выполнить в любом случае».

Ничего дополнительно ставить не нужно: .NET и распознаватель уже внутри. Распознаватель сам выбирает код под процессор — SSE4.2 для старых (Core i5-760), AVX2 для современных (Ryzen).

Если микрофон не записывается: Параметры → Конфиденциальность → Микрофон → «Разрешить классическим приложениям доступ к микрофону».

## Советы

- Говорите в **наушниках**: голоса собеседников не попадут в микрофон повторно (без эха).
- На слабом компьютере выбирайте модель **Small** и режим **«Быстрее»** — расшифровка часа записи займёт порядка 1–3 часов. На современном ПК с моделью Large v3 Turbo (сжатая) — примерно 15–40 минут, на Mac M3 — несколько минут.
